Excalibur Proxy

The auditable, identity-aware egress proxy for AI workloads, CI runners, and agent fleets.

Get it on Azure Marketplace

What it does

  • Identity-aware mediation of every outbound HTTPS request from your workloads.
  • Pluggable credential brokers: mTLS, DPoP, SigV4, PKJWT, GCP SA, Snowflake JWT, HTTP-Sig, Databricks, Azure WIF.
  • Tamper-evident audit trail with optional Azure Sentinel / Log Analytics / Event Hub export.
  • Single static binary; runs on AKS, EKS, Docker Swarm, systemd, or bare metal.

Verify a license

Every license issued from this domain is signed offline with our root Ed25519 key. You can verify the chain yourself without contacting any server: 

excalibur-ctl license verify ./my-license.jws
excalibur-ctl license keys export > trusted.pem
diff trusted.pem <(curl -fsSL https://excalibur.dev/public-key.pem)

The published root pubkey: public-key.pem · Wire format: license-format.md
