Excalibur Proxy

The auditable, identity-aware egress proxy for AI workloads, CI runners, and agent fleets.

Get it on AWS Marketplace Get it on Azure Marketplace

What it does

  • Identity-aware mediation of every outbound HTTPS request from your workloads.
  • Pluggable credential brokers: mTLS, DPoP, AWS SigV4, private-key JWT, RFC 8693 Token Exchange, GCP service-account JWT, Snowflake JWT, RFC 9421 HTTP Signatures, Databricks PAT, Azure Workload Identity Federation.
  • Tamper-evident, hash-chained audit trail with native S3 + KMS + Athena export on AWS and Sentinel / Log Analytics / Event Hub export on Azure.
  • Single static binary; runs on EKS, ECS Fargate, AKS, Docker Swarm, systemd, or bare metal.
  • Self-hosted in your own cloud account: prompts, responses and audit logs never leave your VPC.

Verify a license

Every license issued from this domain is signed offline with our root Ed25519 key. You can verify the chain yourself without contacting any server: 

excalibur-ctl license verify ./my-license.jws
excalibur-ctl license keys export > trusted.pem
diff trusted.pem <(curl -fsSL https://excalibur-enterprise.github.io/proxy_control_plane/public-key.pem)
