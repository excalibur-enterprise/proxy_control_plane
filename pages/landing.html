What happens next


    
  
  1. This page hands your one-time marketplace token to our fulfillment pipeline.
    2. 
  
  2. The pipeline calls your marketplace's own resolution API (AWS Marketplace Metering ResolveCustomer, or Azure SaaS Fulfillment v2) to confirm the purchase.
    3. 
  
  3. It signs a license bundle with our offline operational key (held only in a manual-reviewer-gated GitHub Environment) and commits the signed bundle as a public file into excalibur-enterprise/proxy_control_plane.
    4. 
  
  4. The bundle is served from this GitHub Pages site within seconds. Your proxy auto-fetches it on its next refresh cycle.
    5. 




You can verify the resulting bundle locally with:


excalibur-ctl license verify ./bundle.json
